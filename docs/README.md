# Documentación pública

- [README principal](../README.md): alcance, arquitectura, instalación en Windows, uso, pruebas y limitaciones.
- [Plan del proyecto](PROJECT_PLAN.md): cinco etapas y decisiones arquitectónicas. Las referencias a validaciones internas documentan el proceso local y sus informes no se distribuyen en esta copia pública.
- [Guía de publicación y portafolio](PUBLICATION_GUIDE.md): descripción, topics, revisión de contenido y comandos futuros.
- [Capturas pendientes](../assets/screenshots/README.md): archivos previstos y criterios de privacidad.

Los informes históricos de validación, el informe interno de prepublicación y el README histórico del frontend se conservan en el equipo del autor. Contienen rutas locales o referencias a evidencia y están excluidos de Git. No se trasladaron ni eliminaron. La guía pública de ejecución es el README de la raíz.

Para añadir documentación publicable, revisar su contenido y agregar una excepción específica a `.gitignore`. No incluir automáticamente todo `docs/` ni adjuntar registros, auditorías o PDF privados.
